# Parisaara-Cycle 🚲

Parisaara-Cycle is an Android application developed to promote safe, eco-friendly, and sustainable cycling for students and daily commuters. The app helps users identify safe cycling routes, avoid high-traffic roads, report unsafe road conditions, and track environmental impact through cycling.

##  Problem Statement

Students and workers often prefer cycles for short-distance travel as it is economical and environmentally friendly. However, many face issues such as unsafe roads, traffic congestion, lack of awareness about safe routes, and no platform to report potholes, blocked roads, or dangerous intersections.

Parisaara-Cycle addresses these challenges by providing a digital solution for safer and smarter cycling.

## Features

- Safe route navigation for cyclists  
- Low traffic and cycle-friendly route suggestions  
- Pothole and danger zone reporting  
- Blocked road reporting  
- Nearby cycle repair shop locator  
- Water point finder  
- CO2 savings tracker (Eco-Stats)  
- Buddy system for group cycling safety  

## Tech Stack

- **Language:** Kotlin / Java  
- **IDE:** Android Studio  
- **Maps API:** Google Maps API  
- **Database:** Firebase Realtime Database / Firestore
